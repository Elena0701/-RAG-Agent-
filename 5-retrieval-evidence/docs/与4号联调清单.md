### ① 放文件（不改你的目录结构）

把 `tools/rag_tool.py` 和 `rag_core/` 整个目录放进你的仓库根，与 `tools/rule_tool.py` 同级：

`rag_core/` 必须和 `tools/` 同级，`rag_tool.py` 用 `from rag_core... import` 找它。

### ② 改一行（强烈建议）

`agents/contract_review_agent.py` 的 `retrieve()` 里加 `category`：

```python
return self.rag_tool.retrieve(
    document_id=task["document_id"],
    query=task["question"],
    top_k=task["top_k"],
    category=task["category"],      # ← 新增这一行
)
```

原因（实测，510 份合同 / 6480 个标注片段）：

| 调用方式 | 检索 Recall@5 |
| --- | --- |
| 传 `category` | 71.3% |
| 不传，但问句与 `CATEGORIES` 逐字一致 | 71.3%（工具内部按模板识别） |
| 不传，且问句被改写 | **32.0%** |

不加这行也能跑，但你的 `CATEGORIES` 问句以后**一个字都不能改**。

### ③ 决定入口：`.txt` 还是 `.pdf`

你的 `load_document()` 现在只接受 `.pdf`。CUAD 原文是纯文本，建议二选一：

- **A（推荐）**：允许 `.txt/.json`，`prepare()` 直接吃文本，零依赖；
- **B**：坚持 PDF，那要在 `requirements.txt` 加 `pypdf`（我做了标准库兜底，但只对简单文本 PDF 可靠；扫描件会明确 `FAILED`）。
