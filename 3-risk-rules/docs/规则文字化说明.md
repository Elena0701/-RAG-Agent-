# 合同审核规则文字化说明

## 1 范围与统一约定

审查内容对应 CUAD 已有标注：适用法律地区、续约期限、退出续约通知期限，以及保险、审计权、无因终止的 Yes/No。每项附原文及字符位置。

上游完成条款识别，5 号核验证据；规则模块读取识别答案及核验结果，再执行启用的政策检查。政策参数不是合同事实；允许清单、阈值和等级属于模拟内部政策，不是法律或已核验的市场标准。核心评价不依赖新增风险标签。

所有类别均保留识别答案、原文及核验状态，并生成条款描述；未启用风险政策不影响事实结果展示。核验不足时描述为“无法确认”，不将待核验的模型预测表述为已确认事实。

共用输入仍为接口说明中的九个字段。阈值、是否要求存在、是否提示及等级均为本模块的本地政策参数，不增加上游抽取字段。

**实施状态：**六项政策均已写入统一配置并接入判断程序，见 [政策配置说明](政策配置说明.md)。

### 判断前提

- 正向事实：`processing_status=COMPLETED`、`verification_status=PASSED`，且所依据引用的位置与语义核验通过，才可作确定性判断。
- 不存在事实：Yes/No 类别为 `No` 时，还须 `coverage_status=SUFFICIENT`；不能以空引用列表或一次检索未命中证明不存在。不存在时允许引用与逐条核验列表为空，不编造“否定证据”。
- 已启用规则遇到未知答案、证据冲突、核验失败或必要配置缺失时，返回 `UNCERTAIN`，风险等级为空，并列出原因及复核需求。

## 2 适用法律

### LAW-001 识别地区与允许清单不匹配

| 要素 | 文字规则 |
| --- | --- |
| 必要信息 | 自主识别的适用法律地区、原文和位置；允许地区清单及名称规范化口径 |
| 触发条件 | 单一地区明确、证据有效，规范化后不在允许清单内 |
| 提示等级 | 按政策配置；模拟草案为中，不表示该地区法律本身风险较高 |
| 例外 | 匹配时未触发；多法律、复合答案或条件限制无法可靠比较时不自动判断 |
| 信息不足 | 未识别、证据不足或已启用政策缺少清单时无法确认 |
| 人工复核 | 法律与法院地点混淆、证据冲突、条件复杂或需确认商业可接受性 |

## 3 续约与退出安排

### RENEWAL-001 单次续约期限超过政策上限

| 要素 | 文字规则 |
| --- | --- |
| 必要事实 | `category=Renewal Term`；`category_answer` 为明确的单次续约期限；引用和核验结果支持该期限 |
| 本地政策 | 是否启用、`maximum_renewal_months`、触发等级及人工复核要求；例如演示上限 12 个月 |
| 触发条件 | 可比较的单次续约期限严格大于配置上限 |
| 未触发与例外 | 不超过上限时未触发；`successive 1 year` 可按每次 12 个月比较，不据此累计多次续约总时长，也不推定自动续约或权利不公平 |
| 单位口径 | 仅比较明确的整数月或整数年；1 年按 12 个月归一化。天数不换算为月；范围、多档期限、不定期、条件期限不自动简化 |
| 信息不足 | 答案为空、期限不明确、单位不可比较、证据不足或上限缺失时无法确认；空答案不等于没有续约安排 |
| 人工复核 | 超过上限且政策要求复核，或期限存在条件、冲突、无法比较时复核 |
| 事实描述 | 核验通过时如“识别到单次续约期限为 24 个月”；核验不足时“暂无法确认续约期限” |

示例：上限 12 个月，答案 `24 months` 则触发，`1 year` 则未触发，`until terminated` 则无法确认。等级仅由已启用政策指定，不将长续约期限本身视为通用法律风险。

### NOTICE-001 退出续约通知期限超过阈值

| 要素 | 文字规则 |
| --- | --- |
| 必要信息 | Notice Period To Terminate Renewal 的识别答案、原文和位置；同口径天数阈值 |
| 触发条件 | 答案为明确、单一、以天计的退出通知提前期，且严格大于配置阈值 |
| 提示等级 | 按政策配置；模拟草案为中，仅提示退出安排需要关注 |
| 例外 | 不超过阈值时未触发；仅有续约时长不能执行本规则 |
| 信息不足 | 月、年、复杂窗口、含义不清或证据不足时无法确认，不默认换算 |
| 人工复核 | 原文限制影响期限含义、多答案冲突，或需结合业务决定是否接受 |

原文只写 days 时不补出 calendar days。政策若只比较原文天数，应明确该口径；若要求日历日而原文未明确，则无法比较。无可靠到期日时不计算具体截止日。

数字阈值由版本化政策提供，不作为通用审核标准。

## 4 保险义务

### INS-001 未发现政策要求的保险义务条款

| 要素 | 文字规则 |
| --- | --- |
| 必要事实 | `category=Insurance`；答案为 Yes/No；正向答案有通过核验的引用，No 有充分覆盖检查 |
| 本地政策 | 是否启用、`require_insurance_clause`、触发等级及人工复核要求 |
| 触发条件 | 政策要求存在保险义务条款，且经充分检查的答案为 No |
| 未触发与例外 | 政策要求存在且答案为 Yes 时未触发；政策明确不要求该条款时，本项存在性要求不适用。未启用规则则不执行判断 |
| 信息不足 | 答案未知、No 的覆盖不足、证据未通过、标注语义存疑或政策要求未设置时无法确认，不自动认定保险缺失 |
| 人工复核 | 缺少政策要求的条款，或需确定是否适用豁免、保险安排是否充分时复核；豁免不新增为上游必填字段 |
| 事实描述 | Yes：“存在保险义务条款”；经充分检查的 No：“经本次检查，未发现保险义务条款”；未知：“暂无法确认是否存在保险义务条款” |
| 判断边界 | 只检查合同层面的条款存在性，不判断险种、保额、受益方或实际投保情况，不将 No 表述为不存在任何保险或保险义务 |

示例：`require_insurance_clause=true`，答案 No 且覆盖充分则触发；同样为 No 但覆盖不足则无法确认。触发理由为“未发现本次政策要求的条款”，而非“保险保障必然不足”。

## 5 审计权

### AUDIT-001 未发现政策要求的审计权条款

| 要素 | 文字规则 |
| --- | --- |
| 必要事实 | `category=Audit Rights`；答案为 Yes/No；正向答案有通过核验的引用，No 有充分覆盖检查 |
| 本地政策 | 是否启用、`require_audit_clause`、触发等级及人工复核要求 |
| 触发条件 | 政策要求合同包含审计权条款，且经充分检查的答案为 No |
| 未触发与例外 | 政策要求存在且答案为 Yes 时未触发；政策明确不要求该条款时，本项存在性要求不适用。未启用规则则不执行判断 |
| 信息不足 | 答案未知、No 的覆盖不足、引用不支持审计权类别或政策要求未设置时无法确认 |
| 人工复核 | 缺少政策要求的条款，或需确认权利是否归属本方、是否满足本次业务要求时复核 |
| 事实描述 | Yes：“存在审计权条款”；经充分检查的 No：“经本次检查，未发现审计权条款”；未知：“暂无法确认是否存在审计权条款” |
| 判断边界 | 不新增权利主体、频次、费用等输入；Yes 只说明合同中存在该类权利，不代表本方拥有审计权或权利充分 |

示例：`require_audit_clause=true`，答案 No 且覆盖充分则触发；Yes 时本条存在性检查未触发，但不能据此认定本方受到充分保护。

## 6 无因终止

### TERM-001 发现无因终止条款时提示关注

| 要素 | 文字规则 |
| --- | --- |
| 必要事实 | `category=Termination For Convenience`；答案为 Yes/No；正向答案有通过核验的引用，No 有充分覆盖检查 |
| 本地政策 | 是否启用、`flag_if_present`、关注提示等级及人工复核要求 |
| 触发条件 | 政策要求关注无因终止安排，且经核验的答案为 Yes |
| 未触发与例外 | 经充分检查的答案为 No 时未触发，不解释为合同整体低风险；政策不要求存在性关注时本项要求不适用。未启用规则则不执行判断 |
| 信息不足 | 答案未知、引用不能区分无因终止与违约终止／不续约、No 的覆盖不足或政策参数缺失时无法确认 |
| 人工复核 | 发现相关条款且政策要求复核，进一步由人工评估权利归属、通知安排和商业影响；上述内容不新增为必需输入 |
| 事实描述 | Yes：“存在无因终止条款”；经充分检查的 No：“经本次检查，未发现无因终止条款”；未知：“暂无法确认是否存在无因终止条款” |
| 判断边界 | 触发表示命中关注政策，不说明该条款必然不利于本方，不推定权利不对称、通知期不足或补偿不合理 |

示例：`flag_if_present=true`，答案 Yes 且核验通过则触发，可配置为 LOW 并要求人工复核；不能仅据 Yes 自动判断为高风险。

## 7 输出与评价边界

识别结果与附加规则结果分别保存。规则状态为触发、未触发、不适用、无法确认；仅触发且分级明确时输出配置等级，其他等级为空。

新增四项政策的阈值、要求与等级均需在配置中明确，不默认为行业惯例。本文的 12 个月、LOW 等仅为解释规则的示例值。未执行政策与已执行但未触发应分别表达；事实描述在两种情况下都保留。

未启用政策时，规则结果列表为空，正常保留识别与证据结果，不作为整个任务失败。已启用规则缺少参数时，相关规则无法确认并列出缺项。位置核验不能替代类别与答案正确性评分。

核心评价使用 CUAD 标注。附加提示不参与真实法律风险准确率评价；单独比较固定政策输出时，仅说明端到端政策执行一致性。
