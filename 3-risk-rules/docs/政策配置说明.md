# 六类政策配置说明

配置文件为 [`rules/risk_rules.yaml`](../rules/risk_rules.yaml)。采用 JSON 语法的 YAML 子集，由标准库读取；保留双引号、逗号、布尔值及对象结构。

本配置用于固定测试政策。数值、清单、要求及等级均为项目演示假设，不声明为行业惯例、法律标准或 CUAD 风险标签。

## 1 六项政策

阈值及要求在配置顶层统一维护；各规则的开关、等级和触发后复核要求在 `rules` 下维护，不重复保存参数。

| 规则 | 类别 | 政策参数及当前值 | 触发条件 | 触发等级 | 触发后人工复核 |
| --- | --- | --- | --- | --- | --- |
| LAW-001 | Governing Law | `allowed_governing_laws=["California", "New York"]` | 明确地区不在清单内 | MEDIUM | 是 |
| RENEWAL-001 | Renewal Term | `maximum_renewal_months=12` | 明确单次续约期限大于 12 个月 | LOW | 是 |
| NOTICE-001 | Notice Period To Terminate Renewal | `notice_period_threshold_days=60`；`day_basis="AS_WRITTEN_DAYS"` | 明确天数大于 60 | MEDIUM | 是 |
| INS-001 | Insurance | `require_insurance_clause=true` | 要求存在，且充分检查后答案为 No | MEDIUM | 是 |
| AUDIT-001 | Audit Rights | `require_audit_clause=true` | 要求存在，且充分检查后答案为 No | LOW | 是 |
| TERM-001 | Termination For Convenience | `flag_if_present=true` | 要求关注，且已核验的答案为 Yes | LOW | 是 |

六项 `enabled` 均设为 `true`，六项政策均已接入判断程序。程序测试使用模拟上游识别与核验结果，不代表真实合同端到端评测。

## 2 共用字段与取值

| 字段 | 含义与允许值 |
| --- | --- |
| `rules.<规则编号>.category` | 对应官方 CUAD 类别；用于清晰标识政策，修改类别不等于新增判断程序 |
| `rules.<规则编号>.enabled` | 布尔值；false 表示不执行该项风险规则，但仍保留条款事实与描述 |
| `rules.<规则编号>.risk_level` | HIGH／MEDIUM／LOW；仅在确定触发时输出 |
| `rules.<规则编号>.manual_review_on_trigger` | 布尔值；确定触发时是否要求人工复核 |
| `law_aliases` | 明确地区名称的等价别名，不用于删除复杂法律条件 |

阈值须为非负数，其中 `maximum_renewal_months` 采用整数；保险、审计及无因终止要求须为布尔值，不使用字符串 `"true"`。缺失必要参数时无法确认，不能自动当作 false 或采用隐藏阈值。

`AS_WRITTEN_DAYS` 按答案明示天数比较，不将工作日换算为日历日；`CALENDAR` 只接受明确日历日。续约期限采用整数月或整数年，1 年按 12 个月归一化；不将天数换算为月。不等式均为严格大于，等于阈值不触发。

## 3 人工复核与不适用条件

- **确定触发：**依据 `manual_review_on_trigger` 决定是否复核。风险提示不应通过重复检索来“消除”。
- **无法确认：**已启用规则遇到答案未知、证据未通过、No 覆盖不足、复杂期限、事实冲突或配置缺失时，统一返回 UNCERTAIN、等级 null，并要求人工复核。可由 Agent 先补查；此项是固定的处理要求，不通过关闭触发后复核来绕过。
- **未触发：**风险等级为 null，不因本规则增加人工复核要求；不覆盖其他模块的异常或复核需求。
- **不适用：**INS-001、AUDIT-001 的存在性要求明确为 false，或 TERM-001 的关注要求明确为 false 时，该项政策要求不适用。未知或缺失配置不能当作不适用。
- **未启用：**`enabled=false` 时不执行本规则，区别于已执行但未触发或不适用；上游核验问题仍由 Agent 处理。

## 4 如何修改

例如通知上限由 60 天改为 90 天，只需修改：

```json
"notice_period_threshold_days": 90
```

重新创建 `RuleTool` 实例后生效。答案 90 days 在阈值 60 时触发，在阈值 90 时未触发，合同事实及描述保持不变。程序不会实时监控配置文件变化。

不要求保险条款时可将 `require_insurance_clause` 设为 false；不做任何保险规则判断时可将 `rules.INS-001.enabled` 设为 false，两者含义不同。

对照实验固定同一份配置，参数调整后重新运行相应案例，并将结果与所用配置一起保存。政策判断正确性与 CUAD 条款识别正确性分别评价。
