## 4 运行与结果文件

在模块根目录执行：

```powershell
conda activate FinAI
python -m tests.run_tests
```

也可直接执行 `python -m unittest discover -s tests -v`。测试程序、模拟数据及结果仅保存在本地tests目录。

- `tests/results/test_report.json`：逐用例状态、计数及失败详情。
- `tests/results/unittest.log`：完整执行日志。
