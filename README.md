# -RAG-Agent-

## 项目目录结构（按成员分工）

- `1-problem-data/`：金融问题与 CUAD 数据说明
- `2-theory-design/`：理论框架与研究设计
- `3-risk-rules/`：风险规则与审核标准
- `4-agent/`：Agent 程序搭建与系统集成
- `5-retrieval-evidence/`：RAG 检索与证据核验
- `6-experiments/`：基准实验与结果分析
- `7-case-governance/`：完整案例、风险治理与局限
- `8-slides-integration/`：流程图、汇报材料与最终整合

## 分工与交付

详见[分工与 GitHub 提交清单](./分工与GitHub提交清单.md)，包含每位成员的保存目录、11 月 7 日和 11 月 30 日 DDL、需提交的文件及可供论文/PPT整合的内容标记。

每位成员请在对应文件夹提交负责部分的文字说明及配套代码、数据清单或图表。原始 CUAD 合同数据按许可和团队约定管理；优先提交来源、筛选清单和处理脚本，避免提交不必要的大型原始数据文件。
