# Windows启动与课堂展示

## 1. 默认启动：上传合同并实时审查

直接双击本目录的`start_realtime.cmd`，或用VS Code打开项目，菜单选择“终端 → 新建终端”，在PowerShell复制：

```powershell
Set-Location -LiteralPath 'D:/xsl_use/yanyi/ai/大论文/FinAI/RAG-Agent'
& ./4-agent/code/.venv/Scripts/python.exe -B -u ./7-case-governance/web/app.py --port 8766
```

浏览器打开`http://127.0.0.1:8766`，默认进入**审查工作台**，未登录时右上角显示**历史开放 · 实时需登录**；使用个人邀请码登录后显示**实时审查 · 已启用**。不要在这条命令后加`--offline`；该参数会禁止新增审查。

如果已运行旧版本，请先在原启动终端按`Ctrl+C`停止服务，重新执行上述命令，再按`Ctrl+F5`刷新网页。若端口被其他服务占用，可将8766换成空闲端口，并同步修改浏览器网址，不要随意结束未知进程。

## 2. 邀请码登录、上传及查看真实结果

本机初始邀请码在`7-case-governance/web/data/access/初始邀请码_仅管理员查看.txt`，成员7使用管理员对应的一段；组员只领取本人对应的邀请码。点击右上角“邀请码登录”并粘贴。使用者无需输入API密钥。初始管理员每次最多41类、每日5个任务；普通成员每次最多5类、每日3个任务。详细登录、额度及组员访问步骤见[小组共享说明](SHARING_GUIDE.md)。

1. 上传PDF或UTF-8 TXT合同，单个文件不超过10 MB。只上传合同正文，**不需要人工标注**。推荐TXT在`7-case-governance/contracts/upload_demo/`中。
2. 选择具体Q编号，或使用基础信息、五类重点条款、全部41类等快捷选择。课堂实时演示建议先选1–2类。
3. 保持top-k为5、最大补查为2，或按实际需要调整。
4. 点击**启动真实Agent审查**，阅读条款数及预计请求规模后确认。此时才会调用已有API配置并产生费用；仅打开网页、选择文件和查看历史不会调用模型。
5. 查看实际完成数、当前类别、轮次及八个执行阶段，展开日志查看真实检索、抽取、核验和决策记录。页面每1.5秒读取后台事件，不模拟进度。
6. 完成后点击**查看本次真实报告**。在报告表格中点击条款，再点击**定位并高亮原文**，核对候选答案、实际引文、规范化字符位置、证据状态、规则结果和最终决策。
7. “导出JSON”下载Agent原生报告；“打印报告”打开可读页面，可打印或另存PDF。

若仍显示“离线回放 · 模型已禁用”，需要先用管理员邀请码登录，再点击右上角**启用实时审查**。这一步只启用功能，不启动模型；之后仍需上传、选条款并点击启动。旧版本没有此按钮时，请按第1节重启。

## 3. 历史回放与可选离线启动

正常实时模式同样支持“历史案例”，打开保存的报告不会重复审查、不消耗API额度。历史报告标为“历史案例回放”，新提交任务的结果标为“本次真实审查结果”。

仅在需要主动禁止新增模型任务时，才使用可选离线命令：

```powershell
& ./4-agent/code/.venv/Scripts/python.exe -B -u ./7-case-governance/web/app.py --port 8766 --offline
```

离线模式初始禁止新增审查，保留历史报告、合同全文、证据定位、下载和打印。管理员登录后明确点击“启用实时审查”后可在本次服务中恢复上传审查；下次重新带`--offline`启动仍为离线模式。隔离自动化验收服务禁止此切换。

历史展示可按“报告总览 → 执行轨迹 → 证据溯源 → 人工复核 → 历史案例”进行。CUAD-004保留41类真实案例；在执行轨迹选择Q16可查看实际补查。不要把历史调用数当作正在发生的新调用，也不要为了展示伪造人工复核意见。

## 4. 让小组其他成员通过浏览器访问

双击`start_shared.cmd`，或在原启动命令后添加`--lan`。保持主机终端运行，组员连接同一允许互访的网络，使用终端输出中对应真实网卡的`GROUP_URL`。不能把127.0.0.1发给组员。详见[局域网步骤、网卡选择和防火墙排查](SHARING_GUIDE.md)。

## 5. 停止与输出文件

回到启动服务的终端按`Ctrl+C`。保持终端打开才能使用网页；关闭浏览器不会停止服务。正常退出会停止本服务未完成的子任务，并保留已经保存的断点；已发出的模型请求可能仍计费。

新审查默认仅本人和管理员可见，保存在`7-case-governance/results/web_runs/<任务ID>/`，每次任务目录独立，包含合同输入、原生JSON报告、conversation、JSONL、终端日志、checkpoint及外围进度事件。人工真实提交单独保存在`web/data/reviews/`，不修改原始报告。复核草稿只保留在当前页面内存中。

两种模式均复用原有虚拟环境及API配置，不需要重新配置密钥。详细文件职责和常见问题见[README](README.md)，本轮实时恢复测试见[实时联调记录](REALTIME_RESTORATION.md)。
