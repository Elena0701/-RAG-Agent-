## 1. 零基础Windows启动步骤

### 1.1 打开终端

使用VS Code打开本项目，选择菜单“终端 → 新建终端”，确认使用PowerShell。复制以下命令进入项目根目录：

```powershell
Set-Location -LiteralPath 'D:\xsl_use\yanyi\ai\大论文\FinAI\RAG-Agent'
```

后续命令均在该根目录执行。无需激活虚拟环境，命令直接指定已有虚拟环境中的Python，不受PowerShell激活脚本执行策略影响。

### 1.2 安装网页依赖

本次开发环境已安装Flask 3.1.3，可以直接启动。换到尚未安装Flask的原有环境时执行一次：

```powershell
& .\4-agent\code\.venv\Scripts\python.exe -m pip install -r .\7-case-governance\web\requirements.txt
```

这一步需要下载软件包，但不会调用合同审查模型。不需要重建虚拟环境，也不要重新安装Agent的全部依赖。网页不需要Node、npm、前端构建工具或下载字体。

### 1.3 启动与打开网页

```powershell
& .\4-agent\code\.venv\Scripts\python.exe -B -u .\7-case-governance\web\app.py --port 8766
```

终端出现`LOCAL_URL=http://127.0.0.1:8766`后，在Chrome或Edge地址栏输入：

```text
http://127.0.0.1:8766
```

也可以直接双击本目录`start_realtime.cmd`。默认进入审查工作台，未登录时右上角显示“历史开放 · 实时需登录”，邀请码登录后显示“实时审查 · 已启用”。若正在运行旧版，先在其原终端按`Ctrl+C`停止后重新启动，再`Ctrl+F5`刷新；端口确被其他服务占用时换空闲端口并同步修改网址，不结束未知进程。服务固定绑定本机`127.0.0.1`，没有调试器或自动重启。Flask提示开发服务器属于正常提示；此版本供本地课堂展示使用。保持终端运行，浏览器才能继续访问。

### 1.4 停止服务

回到启动服务的终端，按`Ctrl+C`。正常退出会停止本服务启动的未完成任务，保留此前已写入的原生断点；已发出的模型请求可能仍计费。关闭浏览器不会停止Python服务。再次展示时重新执行启动命令即可。

## 4. 证据定位与字符坐标

Agent证据通常使用规范化文本坐标。工作台只加载现有解析模块中不涉及模型的文本规范化逻辑，不重新实现RAG、模型抽取、证据语义核验或规则判断。

展示前检查规范化文本哈希；原始TXT定位还需要原始文本哈希、位置映射及规范化程序指纹一致。只有位置有效且引文校验成立时才高亮。映射不可靠时，保留引文与规范化位置说明，不强行定位原始TXT。浏览器按Unicode码点切片，避免JavaScript UTF-16索引与Python字符偏移混用。

使用证据卡片中的“定位”按钮可滚动合同阅读区。没有引文的No答案不会生成虚假高亮。“No”表示候选答案认为该类别不存在，并不等于系统未执行，也不天然证明全文不存在。覆盖核验、语义核验和最终决策需要分别查看。

TXT没有真实PDF页码，即使旧解析结构出现逻辑页1也不展示为实际PDF页码。已有报告不能提供的扫描件、OCR或PDF渲染信息不在本轮补造。

## 5. 人工复核与导出

人工复核页首先展示Agent原始升级队列。可单独勾选辅助分析建议，页面会明确区分其来源。六类原因可同时出现：事实/证据无法确认、检索覆盖不足、业务规则命中、上下文综合判断、政策配置不完整、模型API或程序异常。

只有使用者真实填写复核人和意见并提交后，才会创建操作记录。可选择接受、修正、驳回或补充材料；选择修正时还需填写修正答案。记录保存在：

```text
7-case-governance/web/data/reviews/<报告ID>.jsonl
```

每条记录关联原报告哈希、文档ID、条款编号、真实提交时间及操作人。它是成员7新增的外围功能，**不会更新Agent原始报告、自动接收数、原始人工升级数或模型答案**，也不自动回流训练。测试中的表单提交使用临时目录，不生成课堂案例的真实人工复核记录。

“导出JSON”下载原报告文件，字节内容保持一致；如检出已知凭据模式会阻止该下载。页面JSON展示有额外脱敏。原报告只能来自受控本地目录，现有配置文件不会作为报告对外提供。

“打印报告”打开可读报告页，在浏览器按`Ctrl+P`，选择“另存为PDF”或打印机。这是浏览器打印导出，不是另一次Agent运行。

| 现象 | 处理方法 |

| `No module named flask` | 用第1.2节指定的虚拟环境执行安装命令，不用系统Python安装 |
| 8766端口已被占用 | 改用`--port 8767`，浏览器相应打开`http://127.0.0.1:8767`；不要随意结束未知进程 |
| 页面无法打开 | 确认启动终端仍运行，网址协议为`http`，使用本机127.0.0.1及对应端口 |

| 旧报告模型、时间、页码显示未记录 | 原记录未保存该字段，工作台不会用当前设置或推测补齐 |
| 证据无法高亮原始TXT | 检查原文及已有位置映射是否完整；哈希不一致时先查来源，不修改原始报告来强行匹配 |
| 已接受的No仍出现辅助复核建议 | 自动accept与运行后辅助评价属于不同层次，查看建议依据；原始决策不会被工作台覆盖 |

| 选择合同后不能启动 | 检查是否已选择至少一类条款、是否有任务仍在运行；若右上角显示离线，点击“启用实时审查”，或按第1.3节不带`--offline`的命令重启后刷新 |

## 9. 真实上传审查操作

1. 选择PDF或UTF-8 TXT，单文件大于0且不超过10 MB。选择文件不会直接调用模型。
2. 勾选条款，top-k默认5，最大补查默认2；允许top-k为1–20、补查为0–2。
3. 点击“启动真实Agent审查”，阅读调用规模并确认。首轮通常每类约一次抽取和一次语义核验；无法抽取时可能没有语义请求，No覆盖核验、补查及SDK重试可能增加请求。超过5类须额外服务端范围确认。
4. 查看实际完成数、当前类别/轮次、候选数、模型状态、核验和决策。1.5秒读取一次真实事件；只有条款方法真实返回后才增加完成数，不按时间模拟进度。
5. 完成后点击“查看本次真实报告”，检查候选、证据及人工升级。停止按钮会终止本地工作进程；已完成条款断点保留，当前进行中的条款不保证保存，已发出请求可能计费。

按钮禁用、请求ID幂等和每服务单任务避免重复提交。工作进程还有操作系统锁，防止多个服务同时发起审查。网络响应不明时沿用原请求ID；刷新仅恢复最后任务读取，不自动重新运行。历史页可刷新网页任务列表。
