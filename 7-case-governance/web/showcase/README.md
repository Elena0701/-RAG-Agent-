# 明契 · 独立交互式HTML展示版

## 1. 给老师和组员使用

发送本目录的`MingQi_HTML_Showcase.zip`，对方解压后双击“明契_HTML展示版”文件夹里的`index.html`，用Chrome或Edge打开。

也可以直接发送`dist/index.html`这一个文件；页面所需的样式、脚本、三份案例及合同文本均已内置。无需Python、VS Code、Flask、网络、登录、邀请码或模型API，你的电脑可以关机。推荐先解压再打开，不在压缩包预览窗口中操作。

本版本是**真实历史案例交互展示**，不对任意新合同执行AI审查。原有完整实时版继续保留在`web/`中，仍按邀请码和现有后端启动方式运行。

首页现为与实时版保持相同结构的“审查工作台”：左侧选择合同、查看TXT预览并勾选条款，右侧查看历史参数及执行匹配。右上角和工作台固定标明“离线回放”，不会把历史匹配伪装成新审查。

### 最方便的上传交互演示

1. 解压ZIP，双击`index.html`。
2. 在“选择合同文件”选择同目录`sample_contracts/CUAD-004.txt`，或将它拖入上传区域。
3. 页面显示真实文件名称、大小和SHA-256。点击“TXT原文预览”可展开正文；长文件仅预览前20,000个Unicode字符，哈希仍计算完整文件字节。
4. 勾选“五类重点条款”或“全部41类”，点击“匹配并查看真实审查记录”。
5. 页面按文件哈希匹配CUAD-004的原始报告，进入报告页面。所选条款限定表格查看范围，上方统计始终保留原报告完整41项，不改写成新结果。
6. 点击“查看完整原始报告”可恢复完整范围，或点击条款进入证据溯源。

单独发送`index.html`时，对方也可在右侧“从真实案例开始”点击“下载TXT样本后选择”，获得与原文哈希一致的文件。样本下载不添加标题、BOM或额外换行。

### 匹配与读取的准确边界

- 同一文件即使改名，只要字节不变仍能匹配。文件名相同但正文、换行或空白发生变化，也不会仅凭名称套用旧报告。
- 找不到相同文件哈希时，页面提示“未找到对应历史报告”，留在工作台，不加载其他合同的结果。任意新合同需使用完整实时版。
- PDF支持文件选择、大小及SHA-256计算，不在展示版中解析PDF正文。当前内置历史合同都是TXT，因此新的PDF通常没有匹配报告；不得把这解释为PDF已经完成AI审查。
- 选择的是查看范围，不是新执行任务。原报告没有审查过的类别显示灰色“未审查”，不会自动填成No、通过或低风险。
- top-k和最大补查次数为当前已存报告的原运行参数，只读；展示版不能修改参数后重跑。
- 若同一合同有多份已加载报告，需要明确选择哪次真实运行，不默默替使用者决定。

## 2. 内置材料

| 样本 | 原生报告文档ID | 实际审查数 |
| --- | --- | ---: |
| CUAD-001 | `CUAD-001_d0873843` | 5 |
| CUAD-004 | `CUAD-004_7afb02da` | 41 |
| CUAD-008 | `CUAD-008_ba9c81fe` | 5 |

只选取此前已经完成的三份真实运行，不重新调用模型。样本属于成员1清单中的训练侧开发材料；合同正文、规范化文本、可核对的坐标、候选答案、证据、业务规则、补查和日志均读取已有文件。

`dist/source_manifest.json`保存原始报告路径、SHA-256、原文和规范化文本哈希、实际任务数量及构建时间。展示包不包含CUAD原始数据集、gold人工标注文件、虚拟环境、模型缓存、API配置、邀请码数据库、初始邀请码或服务器人工复核记录。

## 3. 建议演示顺序

1. **审查工作台**：选择或拖入CUAD-004 TXT，展开实际原文预览，勾选查看条款，再匹配历史报告。
2. **报告总览**：CUAD-004原报告为41项审查、25项自动接收、16项原始人工升级；查看范围与完整报告统计分开，候选、证据状态、规则模式、风险等级和决策分别解释。
3. **证据溯源**：点击Q36，定位并高亮引用。规范化位置和原始TXT映射分开显示；没有可靠位置时不高亮，不虚构PDF页码。
4. **运行记录回放**：选择Q16，查看真实两轮记录。用“下一条记录”“定位补查记录”切换保存日志，不能把它描述成正在发生的新审查。
5. **人工复核**：查看原始升级原因。可以自行填写本地意见；它不提交服务器、不改变原报告，也不自动成为论文中的人工确认结论。
6. **历史案例**：切换CUAD-001或CUAD-008。未运行的其他类别仍为未审查，不能当作No。
7. **系统说明**：查看政策快照23/3/5/5、责任边界及来源清单。

## 4. 下载、打印与本地意见

- **导出JSON**：下载原生Agent报告，字节与原文件一致，可核对来源清单中的SHA-256。
- **打印报告**：打开独立打印窗口，点击“打印 / 另存PDF”。浏览器阻止窗口时，需要允许该文件打开打印窗口。
- **保存本地意见**：姓名、处理方式、意见由使用者明确填写，不预填或伪造复核人。浏览器支持时保存在其本地存储中，原始审查统计不变。
- **导出本地意见JSON**：单独保存当前浏览器中的意见。导出状态为`LOCAL_NOTES_NOT_SUBMITTED`，记录关联原报告哈希。
- **清除本地意见**：经点击确认，仅清除本浏览器的意见，不影响原报告或服务器数据。

浏览器隐私设置可能禁用本地存储，隐私窗口关闭后也可能清除数据。换电脑、换浏览器、移动文件或关闭页面前，建议先导出意见。导出的本地意见目前不提供自动导入或回流训练。

## 5. 展示案例包导入与导出

在“审查工作台”下方“展示案例包与本地意见”点击“导出当前展示案例包”，得到JSON文件，包含原生报告及必要阅读文本。另一份展示页面可通过该区域的文件选择加载它。

导入只在浏览器本地读取，不上传任何服务器。单个文件不超过20 MB，当前页面最多加载10份案例。检查包括原生报告SHA-256、展示字段、统计、条款目录、风险字段、文本哈希和引用位置；相同原始报告会去重。

**不能直接导入单独的原生Agent JSON并期待完整原文高亮**：它通常没有包含可供阅读的合同全文。请使用本展示版导出的案例包。修改了统计或引用、导致与原生报告不一致的包会被拒绝。

一致性校验不证明外部报告来源真实。新导入材料标为外部导入，来源由提供者确认，不冒充内置真实案例。若需要增加另一份项目真实报告，应在导出器中明确选择并重新构建，而不是伪造数据。

## 6. 文件用途

| 文件 | 用途 |
| --- | --- |
| `dist/index.html` | 独立单文件网页，直接打开 |
| `dist/README.txt` | 给接收者的简短使用说明 |
| `dist/source_manifest.json` | 真实来源、哈希和任务数量 |
| `dist/sample_contracts/` | 三份可实际选择的CUAD原始TXT，字节哈希与内置案例一致 |
| `MingQi_HTML_Showcase.zip` | 可直接发送的展示包，含上述三个入口文件及三份TXT样本，共六个文件 |
| `build_showcase.py` | 读取既有报告，复用当前网页和只读适配器生成展示包 |
| `showcase.js` | 浏览器内数据读取、逐条回放、打印、案例包和本地意见 |
| `showcase.css` | 展示版补充样式，沿用现有专业工作台风格 |

编译产物和ZIP由本目录`.gitignore`排除，避免把合同全文无意提交到代码仓库。需要交作业时手动发送已经核对的ZIP，不把真实配置和账号文件一起打包。

## 7. 在现有环境重新构建

从项目根目录运行：

```powershell
& .\4-agent\code\.venv\Scripts\python.exe -B .\7-case-governance\web\showcase\build_showcase.py
```

只读取已经存在的报告、合同文本和日志，不运行Agent或模型。默认来源固定为上表三个文档ID；缺少真实报告或匹配文本时停止，不自动生成模拟结果。源文件结构变化时也会停止，避免错误拼接。

当前完整网站已统一改名为“明契”，无需为使用展示包启动它。如果需要启动原有实时版：

```powershell
& .\4-agent\code\.venv\Scripts\python.exe -B -u .\7-case-governance\web\app.py --port 8766
```

## 8. 分享和适用边界

展示包无需邀请码，包含的材料随文件即可被阅读。只分发已确认适合分享的材料。没有自动部署到公网、上传到外部平台或推送GitHub。

如以后需要一个网址，可在确认材料公开范围后，把`dist/`作为静态网站发布；Python后端不参与该展示链接。当前文件离线可用，不代表任何外部托管平台已经上线。

完整验收见[展示版测试报告](TEST_REPORT.md)。本地意见、受控测试和已有模型自然运行分别标识，不把软件检查项数当作模型准确率。
